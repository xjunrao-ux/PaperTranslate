# PDF Translate v2.5.0

默认保留原文双栏与图文结构，英文在左、中文在右按段落对齐。中文较长时只增加必要的段后留白，避免整篇展平成单栏或无故推动英文。这次发布包含 v2.0.0 以来的字体规范、流程精简与原生结构修复。

## 主要变化

- 一次确认文章样式，统一正文、标题、图注、表格、脚注及页码的中文字体和字号；顶格与续段不机械添加首行缩进。
- 默认 `paired` 保留栏目并按实际高度补白；`position` 用于严格固定原页，`paragraph` 用于明确选择的自由单栏阅读版。
- 完整保留展示公式、分式、上下标、分段条件和编号；行内公式在独立原生副本中清理邻行字形，并检查公式字形未减少。科学计数法与指数不拆行。
- 复杂表格保留行列、数值、单位、引用和表线，只替换经过核对的自然语言标签。
- 保留脚注分隔线及页眉细线，脚注、页码采用独立小字号；页码单行并沿用原文左右锚点。修正首页署名和机构被当作小标题的问题。
- 明确文字颜色、下划线、彩框、箭头和特殊记号的对等保留要求；无法可靠复现的区域保持待处理状态。
- `regions` 提供有来源映射的公式、图表和段落分组；不能通过删除源块缩减验收目标。合并段落同时检查非公式数字及公式占位符。
- `region-ocr` 对整张图表进行 0°／90° 本地 OCR，覆盖位图、矢量图和轮廓字；结果缓存后由 agent 核对并翻译轴标题、图例，保留数据和数学符号。
- 正常流程精简为准备确认、批次翻译、构建核验三段；模型只读取待译包，复用未变化的结果。引擎脚本指纹纳入修订检查，更新代码后旧缓存自动失效。
- 统一导出中文稿、双语稿、审阅报告、QA 和清单；未完成输出带草稿标记，不能通过手改状态绕过验收。

## 下载与安装

- `pdf-translate-v2.5.0.zip`：通用目录型技能包，供 Codex、DeepSeek Harness 等宿主使用。
- `pdf-translate-workbuddy-v2.5.0.zip`：使用同一核心脚本，补充 WorkBuddy 元数据。
- `SHA256SUMS-v2.5.0.txt`：两个安装包的 SHA-256 校验值。

解压后将整个 `pdf-translate` 文件夹导入宿主技能目录。项目中的 `scripts/install_skill.py --update` 可更新个人 Codex 安装，更新前逐文件备份并校验结果；其他目录使用 `--destination` 指定。

```text
python -m pip install -r <skill>/requirements.txt
python <skill>/scripts/pdf_translate.py doctor
python <skill>/scripts/pdf_translate.py start paper.pdf --job jobs/paper
```

基础环境为 Python 3.10+，PyMuPDF 固定为 1.26.7；图片／扫描件和图表 OCR 另装 `requirements-ocr.txt`，推荐 Python 3.10–3.12。译文由调用 skill 的模型提供，不需要单独的翻译 API。中文字体不随包分发，跨机器保持一致需使用相同的合法字体文件。

旧版任务不要直接覆盖或重新分段；备份后沿用原协议，必要时新建任务并核对后复用译文。更新 skill 不会自动修复已导出的 PDF。

## 验证与边界

- 74 项自动测试覆盖实际 PDF 构建、字体资源、段落补白、图表标签、公式清理、来源清单、数字守恒、OCR 缓存及导出验证。
- 对 22 页回归文献逐页检查双语输出，并使用 PDFium 独立渲染全部页面，重点核对表格、公式、脚注和图中文字。
- 发布包仅含技能文件，不包含用户论文、译文、工作任务、字体或凭据。
- 通用包和 WorkBuddy 包共享核心实现，但尚未完成所有宿主中模型执行流程的端到端实测；宿主需支持 Python、本地文件、命令及视觉核验。
- 复杂背景、批注、高难度公式和表格仍可能需要人工修正。当前弹性对齐可增加页高，尚不自动拆成标准纸张续页。自动检查不能代替专业译文审校或逐页视觉检查。
