# PDF Translate v2.0.0

英文 PDF 和图片可生成保留版式的中文译文，以及英文在左、中文在右的内容块对照 PDF。本版新增强调格式保留、本地图片 OCR 和 PDF 内嵌附件翻译。

## 功能

- 保留整段及段内粗体、斜体、下划线、删除线、等宽文字与上标。段内样式按译文语义标注；中文粗斜体采用视觉等效处理。
- 支持可提取的 90 度图表标签，保留文字方向和对应区域。
- 支持 PNG、JPEG、BMP、WebP 和多页 TIFF，以及扫描 PDF 和 PDF 内部位图的可选本地 OCR。
- 经核对的均匀背景文字区域可原位翻译；支持深色背景上的浅色文字。复杂背景保留原图并报告待处理区域。
- 图片任务导出译文 PDF、双语 PDF 和逐页 PNG。
- 安全提取 PDF 内嵌附件；支持的 PDF／图片进入独立翻译任务。核验完成的附件译文 PDF 可嵌入主输出，附件变化会使主输出失效。
- 沿用术语表、`中文（原英文）`、疑难项与用户裁决、断点续跑和输出检查。
- 安装更新前备份旧文件，并核对复制结果的 SHA-256。

## 下载与安装

下载本 Release 附件 `pdf-translate-v2.0.0.zip`，解压后将整个 `pdf-translate` 文件夹导入宿主的技能目录。`SHA256SUMS.txt` 提供安装包校验值。

在项目虚拟环境中安装依赖：

```text
python -m pip install -r <skill>/requirements.txt
python <skill>/scripts/pdf_translate.py doctor
```

需要图片／扫描件 OCR 时，使用 Python 3.10–3.12，并安装：

```text
python -m pip install -r <skill>/requirements-ocr.txt
```

基础功能要求 Python 3.10+，核心 PDF 依赖固定为 PyMuPDF 1.26.7。译文由调用技能的 agent 提供，脚本不自行调用翻译 API；本地 OCR 运行时不上传文档。

旧任务使用 `refresh-styles <job>` 恢复源格式，再检查译文样式映射、重新排版和核验。保留原任务备份。

- 在 Windows、Python 3.12.14、PyMuPDF 1.26.7 环境下通过全部 26 项测试，包括实际 PDF 格式绘制、真实本地 OCR、多页 TIFF、附件嵌入和更新失效检查。
- 通过技能结构校验及安装包内容校验。
- 对 ASIC-Agent 示例文献的 7 页译文、7 页双语页及 4 页译注完成视觉检查。用户文献、任务缓存和译文不包含在发布附件中。

## 已知边界

- 当前翻译流程针对英文到简体中文；复杂公式、特殊字体、复杂表格及图片背景仍需审阅。
- 内容块对齐不代表中英文逐行等高；空间不足时输出明确标记的草稿，不通过截断或删除译文消除警报。
- OCR 不自动恢复图片里的粗斜体，需查看源图并标注；透明图片按白底合成。
- 不自动翻译 Office、压缩包或音视频附件，不保证交互表单与数字签名保真。
- 通用脚本与具体模型解耦，但目前未完成 DeepSeek Harness、WorkBuddy 的实际运行验收；其他宿主可能需要调整技能元数据、安装路径和权限。
