# v2.4 弹性段落对齐

用户明确：英文 5 行、中文 8 行时，在英文段末增加约 3 行留白，使下一段对齐，同时保留双栏和图文结构。因此默认 build 改为 paired；position 仍为严格原页，paragraph 仍为显式自由单栏。

paired_layout.py 按实际高度差补白，两栏分别累计，跨栏对象同步衔接。原文字形和图像不拉伸，下一对段落起点一致。英文较长时在中文段后补白，不在 JSON 中插空行，不缩正文。

当前一源页对应一输出页，允许输出页增高，未自动拆成标准纸张续页。超过 PDF 高度限制或图内标签未解决时保持草稿。保留栏目和原字形不等于严格原页像素不变。

回归覆盖五行／八行补白高度、两栏独立推进、跨栏图衔接和实际双语段落起点。另逐页查看自造双栏示例；不代表用户论文已完成重新排版。

验证结果：61 项自动测试通过；skill 元数据及两个分发包的核心一致性检查通过。
