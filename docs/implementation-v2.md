# v2 实现与验证记录

日期：2026-11-11。技能名仍为 `pdf-translate`，引擎版本为 `2.0.0`，兼容 v1 任务数据；旧任务需要恢复样式并重新排版。

## 格式保留

- 记录源字体/字符标志、字号、颜色和基线。
- 整段一致格式自动继承；混合格式必须为对应译文提供语义字符范围，不能按字符长度比例映射。
- 保留粗体、斜体、下划线、删除线、等宽片段和上标。当前中文使用视觉等效的描边加粗与几何仿斜，不声称存在完全相同的中英文字形。
- 术语占位符展开后的中文与括号英文继承同一格式；范围不能切开占位符。
- 缺少原文强调形式或未标注混合格式时输出草稿，不能用裁决跳过。
- 支持可提取的 90 度竖排标签翻译，保持对应方向和区域。

## 图片与附件

- 支持 PDF、PNG/JPEG/BMP/WebP 和多页 TIFF；图片保留帧顺序和页面尺寸。
- 可选本地 OCR：`rapidocr-onnxruntime==1.4.4`，Python 3.10–3.12；模型随依赖安装，运行时不上传文档。
- OCR 可用于扫描页、独立图片和 PDF 内部位图；已有原生文字不重复提取。
- OCR 文字、字体和覆盖区域需人工核对。识别错误可先修正，再翻译导入；旧响应自动失效。
- 均匀背景区域可覆盖英文、写入中文，采样原文字颜色，支持白底黑字和深底白字。矩形外图像保持不变；复杂背景拒绝自动覆盖。
- 图片任务导出两份 PDF 及各页 PNG。透明图片按 PDF 白底合成，不保留导出 PNG 的透明通道。
- PDF 内嵌附件按安全文件名提取，支持的 PDF/图片进入子任务，其余格式明确列出，不执行附件。
- 子任务完成并核验后，其译文 PDF 嵌入主译文和双语 PDF；原始附件仍保留在主译文中。子任务的输入/译文/输出修改会使主输出失效。

## 自动化验证

执行：`.venv/Scripts/python.exe -m unittest discover -s tests -v`。

共 26 项测试：保留 v1 的 14 项，新增 12 项格式与媒体测试，覆盖：

- 混合格式缺失时阻塞；粗斜体不仅存在于 JSON，还实际绘入 PDF。
- 整段粗斜体继承、下划线及删除线的实际矢量绘制。
- 样式范围不能切开术语占位符。
- 纵轴文字翻译及旋转方向保留。
- 使用真实本地 OCR 识别图片英文，导出 PDF 与 PNG，确认远离文字区域的像素保持不变。
- OCR 未核对时拒绝导入；复杂背景不自动覆盖；深色底上的白字译文仍为白字。
- 多页 TIFF 保留全部帧。
- 附件路径清理及子任务准备；已翻译附件嵌入主 PDF；子任务改变使主输出失效。

测试中的视觉确认状态机使用隔离夹具模拟，不用于替代实际交付文档的视觉核验。

## ASIC-Agent 文献验证

保留旧版任务和成品，新任务为 `jobs/asic-agent-v2`。沿用已完成译文，恢复原文样式并按语义标注，修复一个将相隔很远的两个图标签混在一起的内容块。

新版共 469 个内容块：159 块翻译，310 块保留（包含数值、工具标识、授权信息和参考文献）。保留摘要与关键词的加粗、段内/独立小标题斜体及注号上标；图 1/2 通用标签原位翻译，图 3 纵轴保留旋转方向翻译。标签利用节点内留白保持居中，并避开图标；曲线、箭头、图标和数值未重绘。

自动回提取全部译文并核对块起点及数值，另外逐页查看译文、双语 PDF 和说明页。左侧原文在 72 DPI 下除第 3 页少量抗锯齿差异外逐像素一致；容差及差异计数如实记录，未宣称完全一致。

## 边界

不自动处理复杂数学重建、任意背景的图像文字修复、Office/压缩包/音视频附件、复杂旋转和交互表单/签名保真。字体元数据或 OCR 不能证明源格式和语义识别完整，最终仍需人工审阅。PDF 内部图片通过文字层覆盖翻译，源图片副本始终保留。
