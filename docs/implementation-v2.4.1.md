# v2.4.1 特殊标注

新增明确规范：语义下划线／删除线、文字颜色、高亮、彩框边色／底色／虚实线、箭头、脚注记号与圈号须与译文对应；paired 补白后标注随所属段落或图组移动。统一字体不得覆盖有语义的颜色。

脚本将文字颜色纳入编号格式锚点，按对应译文片段绘制，装饰线继承片段颜色。新增特殊文本记号缺失检查，原生公式中的记号不重复要求。OCR 保留原来的前景采样策略，避免默认黑色覆盖深背景上的浅字。

原生彩框等图形仍通过原 PDF 图组保留；独立矢量下划线、复杂透明高亮及批注层并非均能自动识别映射。规则要求逐页核对，未可靠复现者明确报告并保持未完成，不声称任意标注均已实现自动处理。

彩框处理补充：可用区域扩展到真实的提示框内部，同时用其他标签边界约束空间，避免把大框当成可以覆盖整个区域的许可。嵌套红／蓝框和对应标签颜色已加入实际 PDF 构建回归。

验证结果：66 项自动测试通过；技能元数据和通用／WorkBuddy 分发包一致性校验通过。
