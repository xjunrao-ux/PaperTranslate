# v2.3 页面保真与结构检查

本版依据 ASIC-Agent 真实交付物审查修改技能规则与核心脚本，未改写用户 dsHarness 任务或发布远端 Release。通用包与 WorkBuddy 包共享核心实现。

## 已实现

- build 默认 position：左侧完整嵌入原页，右侧原位替换，保留双栏和跨栏图表；不再默认展平成单栏。只有显式 --alignment paragraph 才自由重排。
- 每页在独立临时 PDF 中执行删字和绘字，再汇入译文；避免跨页共享字体资源写坏。内存、保存后及最终验收均检查字体资源是否真为 /Font，拒绝将内容流当字体。
- 首行缩进按字体 em 计算，正文默认 2em；列表悬挂缩进，标题／摘要／图注不机械缩进。build 不再允许逐块缩正文以隐藏溢出。
- 角色识别优先看单元格容器，识别常规字重主标题、罗马编号和字母小标题、Fig.／TABLE 罗马编号图表注；首次输出实际角色样例供统一确认。
- 恢复同基线英文碎片与后续行，阻止独立标题被重新合并进下一段。
- 结构检查阻止合并的小标题、错误标题角色及译文相互覆盖。显式重排模式额外阻止竖排版权进入正文流和重叠原文裁片可能造成的重复内容。
- QA 的 complete 不能由视觉核验声明绕过结构和资源检查。缓存加入引擎版本，避免复用旧引擎成品。旧协议报告时间改取已有构建／审阅时间，重复导出不再因当前时间变化发生碰撞。

## 真实文献验证

在工作区隔离复制旧任务，复用已有译文，构建原位 7 页中文稿和 7 页双语稿。保存后所有页字体资源检查通过；旧原位尝试中第 4 页 F10 指向内容流的问题未复现。

7 页左侧与源页逐像素比较：6 页完全相同，第 3 页仅 5 个颜色通道相差最多 2，符合现有抗锯齿容限。检查了首页预览：原页双栏、标题和作者位置保留，竖排版权不再占正文高度。

新提取能够恢复 query_docs 的完整说明句、LLM-Powered Evaluation Framework 的连续段落，并把 B. Qualitative Insights 单独识别为小标题。主标题识别为 title，Average 为 table。

旧任务原位重建仍有溢出和结构阻塞，输出明确为 draft，未导出为用户正式论文。隔离实验不是对整篇译文的重新审校或修复完成声明。

## 边界与工作流

当前脚本没有自动中文续页或任意双栏弹性重排能力。放不下时应修正真实边界并提出具体区域调整；需要新增续页时先给出可审阅方案，不能擅自换成单栏或伪称已实现续排。字体表统一不代表每个块都分类正确，首次须检查实际角色样例。

新增回归覆盖默认完整原页、首行缩进、标题与表格优先级、碎片恢复、标题边界与字体资源损坏；旧协议和显式自由重排继续验证。机器检查不能证明翻译语义或所有视觉细节正确，仍需按页面契约逐页核验。

验证结果：58 项自动测试通过；SKILL.md 元数据校验通过；隔离原位草稿第 4 页经独立 Poppler 渲染成功，未出现原先的 F10 字体资源错误。
