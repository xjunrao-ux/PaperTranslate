# v2.1 字体、段落与导出约定

引擎版本为 `2.1.0`，兼容现有任务数据。已发布的 `v2.0.0` 不覆盖；本次更新为工作区源码和本机技能更新。

## 用户要求与实现

- 中文按源字体类别选择宋体／黑体等相近字体，保留字号层级和实测基线间距，记录实际字体及字节哈希。跨机器一致性需要提供同一字体文件。
- 黑体类别与粗体字重分别识别，结合 PDF 标志、名称、嵌入字体 face 属性和视觉核对。`typography` 命令允许有依据的修正，保留原始信息。
- 不照搬逐行硬换行；按中文标点禁则折行，保护数值和单位，保留真实结构与显式换行，避免可调整的孤字末行。
- 对齐单位是段落／内容块。`render --alignment paragraph` 将左右段落组成同高行，在较短一侧段后留白，使下一段重新对齐；中文优先使用原字号。段落模式会重排原栏目并可能增加页数，不宣称左侧逐像素保持原页。
- 图、表及连通矢量区域成组保留，不把每个单元格当成独立正文段落。超大段落、复杂公式和仍然溢出的单元格需进一步处理，不能冒充完成。
- 小标签不强制放大；取消单行额外整行高度和表格固定大留白。对字体包络超出单元格的情况检查基线归属，用安全的中心带删除原字并保护相邻行与图线。
- `export` 统一语言、修订号、草稿标志和清单；不同内容不覆盖，未核验不能导出正式版。

## 验证

原有 26 项测试加 13 项新回归，共 39 项。覆盖真实字体嵌入、字号与基线间距、5.1 pt 标签／5.6 pt 表格行高、字重误判修正、标点与单位换行、段落留白、整表保留、区域扩展收敛、命名与重复／过期导出。

完整测试通过后，对换行孤字优化及段落栏宽归一再次运行字体／导出回归。综合演示为 `examples/build_typography_demo.py`，使用自造文档与已知译文，不含用户文献；预览及任务存于 `output/typography-demo-v2.1`。

综合演示曾暴露图表区域扩展未写回列表的循环问题，已经修正并增加收敛上限及专项回归。临时诊断进程触发过 Windows 即时调试提示，相关测试进程已结束；演示脚本只对自身进程关闭崩溃交互窗口，不修改系统设置。

截图并非原 PDF，不能据此确认其中所说的 63 个单元格和 35 个图标签已修复。实际文献需提供原文件与报告后逐格核对。
