# v2.5 原生结构与最小扰动排版

针对 1904.04489v1 的审查结果修正核心引擎，复用既有译文另建 r02 任务，保留旧交付。修复不仅是 skill 文字要求，也进入所有宿主共用的 CLI。

- 左侧以原生页面条带复制；无必要补白时维持原位置及矢量线。原文段距不继承中文段距。栏归属容忍轴标题轻微越过栏沟，避免右栏图错误同步推动左栏。
- 展示公式含编号整体保留；根号、分母、上下标和分段条件不独立入流。行内公式在独立原生副本中清理邻行字形，逐字形核对保留内容未减少，避免裁框带入邻行碎片。普通文字回提取按字体、位置和基线核验；科学计数法与指数不拆行。清理不可靠时阻止交付，不改写数学含义。
- 表格原生结构整体保留，只覆盖核验过的自然语言标签；源数值、希腊字母、单位、引用及三线表不重打。
- 脚注与页码使用独立小字号角色。零高度／零宽度线条也复制到中文侧；脚注保持分隔线，页脚无首缩且跟随源锚点左右对齐。正文缩进参考原结构，顶格和续段不机械加 2em。
- 首页作者单独识别，署名保留原拼写与机构上标；机构采用统一小字号，明确换行。不会因首字母 A. 被当成附录小标题而强制加粗。
- `regions` 登记完整公式、表格、图和合并段落；源块不删除，来源清单在构建时检查。QA 分开报告源块、分组覆盖数和排版段数，避免混加。
- 合并段落的非公式数字和占位符同时校验；引擎脚本指纹纳入任务修订，脚本更新也会使旧缓存和旧视觉核验失效。
- `region-ocr` 对已登记的整张图／表做 0°／90° 本地识别，缓存结果；支持位图、矢量图和轮廓字。候选须去重和核对，再登记译文标签。数字、刻度、曲线与数学变量不随 OCR 改写。

普通文档仍用准备、批次翻译、构建核验三段流程；区域修正和 OCR 为条件步骤。保留旧任务的已确认字体方案；新版支持脚注、页脚、作者和机构的固定样式。未通过实际看图的成品仍不能标记完成。

跨宿主通过同一 Python／JSON 协议共享实现，不依赖 Codex 专用翻译 API。分发包可用于目录型技能宿主；DSH、WorkBuddy 内的实际执行能力仍需各宿主支持本地文件、命令和视觉核验，不能宣称已经完成所有宿主端到端测试。

验证：74 项自动测试通过；原文 22 页完成构建与逐页视觉检查，并使用 PDFium 独立渲染全部页，复查重点公式、表格、脚注和图内标签。源内容保持 274 块，43 个可追踪区域覆盖 56 个源块；224 个译文排版段与 2 个独立保留块分开统计。通用／WorkBuddy 包共用 21 个分发文件，逐项一致性与元数据校验通过。Codex 和 DSH 已安装目录均同步为 2.5.0，并先行备份；尚不等于已完成两个宿主中模型执行流程的端到端实测。
