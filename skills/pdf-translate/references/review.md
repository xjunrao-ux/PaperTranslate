# 翻译与裁决规则

## 保真翻译

按全文语境翻译，不把作者的猜测变成确定结论，不删除限制、否定或条件。保留数值、单位、正负号、公式和引用编号。不要将识别不清的负号、小数点、上标或字母当作已确认数据。每个块完整翻译；模型输出长度不是完整性的证明。

专名用用户指定或有依据的译名，加实际原英文。对没有可靠中文名的人名，可先保留英文并列出音译建议，交由用户决定。引用作者和文献条目优先保留可检索原名。只在原文确实出现时使用全称或缩写，不自动补造。

## 疑难等级

- `major`：影响核心概念、结论、数据、身份识别，或源文识别不可靠。草稿可以继续生成，但问题解决前不能标记完成。
- `minor`：措辞选择、风格、无需改变事实的细微歧义。采用说明过的推荐译法并记录；如果用户要求逐项确认，提升为 major。

区分三种问题：

1. `ocr` / `source`：原文或提取结果不清。给原页局部截图、识别候选和具体位置。
2. `ambiguity` / `term`：译法不确定。给原句、上下文、候选译法、差异、推荐和依据。
3. `author_claim`：原文内部矛盾或论断可能有问题。忠实翻译，将异议放在审阅报告，不能直接修正作者的数据、结论或实验条件。

在每页中对不同问题分别记录。集中向用户呈现真正需要选择的项目，优先解决会影响后文的大范围术语；等待回复时继续独立工作。没有收到用户回复时不得写 `--actor user`。常规措辞可由 assistant 记录判断，但重大、实质性歧义不能通过自行标记裁决假装获得用户认可。

## 检查范围

自动检查能发现：缺块、过期响应、名称占位符丢失、部分数值变化、字体缺字、版面溢出及输出坐标异常。它不能证明语义无误、术语识别完整、表格读取顺序正确或每个图中都没有英文。

先检查全页预览，再放大图表和报警区域；对照关键结论、否定、统计术语和单位。表格应按行列比对，不能因文本能提取就认定结构正确。任何保留原文区域、图中文字补充翻译及人工裁决都在最终报告中明确说明。

PDF 签名、注释、表单和链接的交互状态不在完整保真范围。双语页保留原文可见内容需要实际验证；不做未经说明的签名或表单处理。OCR 识别后的字体和强调形式需根据源图手工核对；复杂背景和图线不得自动覆盖。
