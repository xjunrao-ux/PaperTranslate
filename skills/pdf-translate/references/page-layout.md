# 保留栏目并按段落补白

默认 paired：直接复制原文内容，保留字形、栏目、图形与原段距。中文确实超长才加必要留白，推动受影响的后续对象；没有溢出时左侧保持源位置。原文页脚随实际增高移动到页底。

## 补白规则

每对段落占用高度 = max(英文实际高度, 中文实际高度)。英文段后补白 = 占用高度 − 英文高度；中文侧同理。在补白之外保留正常段间距。

英文 5 行、中文 8 行，同行距时英文段后补约 3 行高。字体／行距不同时按实际高度计算，不机械相减行数。不在 JSON 中填空行，不缩小正文配合。

| 对象 | 规则 |
| --- | --- |
| 双栏 | 两栏分别累计补白，各段保留原来的栏位置，不串成一条长列。 |
| 跨栏标题、整图 | 等前面两栏都排完后统一衔接，不拉伸字形和图像。 |
| 独立小标题 | 与正文分块，不能合并进下一段；段内引题保留原结构。 |
| 正文 | 中文行距 1.35 倍、适度段距；原文有缩进采用 2em，顶格与续段为 0。不能把中文段距作为英文的最小间距。 |
| 脚注、页脚 | 脚注约正文 0.75 倍、行距约 1.2 倍，保留注号和分隔线；页码同档小字号单行、无首缩，按源锚点左右对齐。 |
| 页边对象 | 竖排版权和页眉不占正文流高度；页脚随增高页底移动，不插在标题与作者之间。 |
| 图表 | 原栏位与顺序保留；内部标签先解决真实溢出，段后补白不能修复表格内碰撞。 |
| 参考文献 | 可保留英文；保留整区避免裁片重叠复制作者、网址；块数不是条目数。 |

当前一源页对应一输出页，必要时输出页增高，不拉伸内容；暂不自动拆成标准纸张续页。超过 PDF 高度限制时保持阻塞并提出明确拆分方案。此模式不是严格原页像素一致。

## 其他模式

- position：固定原页，左侧完整原页，逐页像素检查；中文放不下时不能自动补白或宣称完成。
- paragraph：显式选择的自由单栏阅读版，会展平原双栏，不能作为 paired 的替代效果。

用户允许英文段后加空白即采用 paired，不再询问是否允许推动后续段落。重新要求严格原页才改用 position。原 PDF 不改写。

验收：段落起点与实际留白、双栏归属、跨栏衔接、图注和页边对象、重复内容、缩进、译文完整性及字体资源。复杂源页逐页看图；不能把版权条占满正文、重复裁片或图文错位解释为正常留白。

特殊标注与段落／图组绑定：补白推动后续内容时，下划线、彩色框、高亮、箭头与脚注记号同时移动；颜色类别、连接方向与标注范围都须对等。见 [媒体与标注规则](styles-media.md#特殊标注与图形语义)。

## 可追踪的区域修正

仅提取有误或复杂对象需要时使用；普通段落继续批次翻译，不逐块登记。保存 `{"regions":[...]}`，运行 `regions <job> <file>` 再 `build`。所有坐标为源页 pt，页码从 1 起。文件替换当前区域清单，后续修正保留其余条目。

每条有 `id`、`page`、`bbox:[x0,y0,x1,y1]`、`kind`、`source_ids`、`reason`。源块不删除、不改写；一个块最多归一组，登记与构建均检查来源清单。类型：

- `formula`：完整展示式与编号一起裁取原生 PDF，不翻译或重打式子。
- `table`／`figure`：整区保留。`reviewed:true` 加 `labels:[{"source":"Value","text":"取值","bbox":[...],"font_size":7.5}]` 替换经过核验的自然语言标签。竖轴用 `rotation:90`；遮罩限于文字，不盖曲线／刻度。边界或可读字号放不下先调整留白或布局，不能删除单元。
- `paragraph`：把被公式拆碎的源段绑定为一段；给完整 `translation`、可选 `style_role`、`styles`（字符范围保留科学计数法指数等强调）。公式用 `⟦M0001⟧` 及 `native_math:[{"token":"⟦M0001⟧","bbox":[...],"baseline":123.4,"source_size":10}]`，边界包括根号与上下标。脚本在独立原生副本中清理邻行字形，核对公式字形未减少；特别高的上下标可提供源基线范围 `baseline_window:[最小值,最大值]`，不能靠扩大裁框带入邻行。

`reason` 记录实际视觉依据。不能用 `reviewed:true` 代替查看原图。全图标签核验包含轴标题、图例和嵌入说明；无自然语言也记录结论。构建后核对整式、编号、表格逐行对应、标签和源块覆盖，再进行 `finish`。

矢量／轮廓字图先登记整图，再运行 `region-ocr <job>`。本地 OCR 在 0°／90° 两个方向识别，只返回自然语言候选到 `region-ocr.json`；按源文件指纹、区域和 dpi 缓存。核对、去重、翻译后将候选写为 `labels`，再次 `regions`、`build`。不必将一整页重新 OCR，也不必让每个 agent 重写旋转坐标转换。没有 OCR 依赖时用本技能 `requirements-ocr.txt`；候选不是已完成翻译。
